## Ejercicio 1. Actualización del sistema en Windows Server 2022 
![Imagen 1_1](img/1_1.png)
Para actualizar el sistema en Windows Server 2022, es necesario acceder a la configuración, que encontraremos al desplegar el botón de inicio
y la identificaremos por un símbolo de "tuerca". Una vez dentro de la configuración, debemos buscar el asistente de actualizaciones, que lo encontraremos con el nombre ``Actualización de seguridad`` o ``Windows update``. Una vez dentro podemos ver que este asistente, como bien su nombre indica, busca actualizaciones disponibles para el sistema. Si el asistente encuentra alguna actualización debemos de instalarla, podemos ver que nos ofrece información acerca de la actualización como para qué es la actualización o la versión de la misma que se va a descargar. Si nos desplazamos abajo en el asistente, observamos que nos permite pausar las actualizaciones automáticas, seleccionar en qué horas queremos o no instalar actualizaciones y opciones avanzadas que nos brinda acceso a activar o desactivar las notificaciones o descargar las actualizaciones por conexiones de uso medio.

La diferencia entre las actualizaciones de seguridad, de característcas y de controladores es que las de seguridad, son las más importantes ya que suelen corregir parches de seguridad que antes eran brechas por las que pueden robarnos informacion, y que si no instalamos rápido puede suponer un riesgo. Las actualizaciones de características suelen ser cambios en parámetros estéticos o de funcionalidad que no suelen suponer ningún peligro. Por último tenemos las actualizaciones de controladores o drivers. Estas actualizaciones sirven para los periféricos o hardware en general.
![imagen 1_2](img/1_3.png)
Aquí podemos observar que ya dispongo de todas las actualizaciones instaladas.

Es súmamente importante mantener actualizado el sistema de Windows Server 2022, pero no únicamente este servidor sino cualquier servidor, esto se debe a que cuando sale una nueva actualización se debe en la mayoría de los casos a errores del sistema que permiten crear brechas por las que nos pueden robar información o realizar cualquier cosa con el servidor.
